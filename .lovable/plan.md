# Iftiin Academy Marketing Website

## Goal
Build a polished, single-page website that turns QR-code visitors into course browsers and WhatsApp/Skool enrollments.

## Page structure
- Sticky anchor navigation for Home, Courses, How It Works, Testimonials, and Contact.
- Full-width opening section with the supplied headline, supporting copy, two enrollment actions, generated diaspora learner artwork, and country trust strip.
- Four concise “Why Iftiin” value cards.
- Main course catalog organized by eight track tabs, with flagship tracks emphasized and every requested course included.
- Three-step enrollment section with payment choices and a prominent WhatsApp action.
- Three clearly marked placeholder testimonials with generated avatar artwork.
- Simple founding-team role cards using initials.
- Compact footer with navigation, social links, WhatsApp, and the currency note.

## Visual direction
- Deep teal and indigo foundation, warm amber accents, and an off-white background.
- Bold contemporary sans-serif headlines, clean readable body copy, high contrast, and generous spacing.
- Premium editorial composition with restrained patterns inspired by light and Somali cultural geometry.
- Subtle scroll reveals, polished card movement, and reduced-motion support.
- Mobile-first layouts and stable controls designed for fast QR-code traffic.

## Imagery
- Generate one primary learner image and a cohesive set of tasteful course images.
- Reuse artwork thoughtfully across related course cards to keep load time practical while ensuring every course has relevant imagery.
- Generate three illustrated testimonial avatars; no real-person photography or copyrighted branding.
- Optimize delivery and lazy-load non-critical images.

## Content and interactions
- Write warm, practical descriptions for all requested courses and assign suitable Flagship, Popular, New, or Top Pick badges.
- Build accessible track tabs with a mobile-friendly selector and keyboard support.
- Use placeholder WhatsApp and Skool URLs consistently, ready to replace later.
- Add semantic sections, one H1, descriptive image text, and complete page sharing metadata.

## Verification
- Check desktop and mobile rendering, navigation anchors, track switching, external buttons, image loading, text fit, and reduced-motion behavior.
